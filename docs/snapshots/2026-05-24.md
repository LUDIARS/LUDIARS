# LUDIARS サービス状況スナップショット (2026-05-24)

LUDIARS org の現役 **公開** リポジトリ (services.json 登録済 43 件 + Foundation 概念) を、
ローカルクローンと GitHub API から解析した週次スナップショット。前週
(2026-05-17) からの主な変化は冒頭サマリと「前週との比較」節に
まとめます。

**ルール変更 (2026-05-24)**:
- 進捗計算 (`weighted_completion`) は **planned カテゴリのリポを 0 として算入** (= 進捗バーは表示しない / 数値計算上は 0 として平均に寄与)、 全 services.json 公開リポ (Foundation 除く) の算術平均を取る。
- **Tessera (network → planned)** に移動 (実装本格着手前)、 **Lictor を services.json `local` カテゴリに新規登録**。
- **VantanHub は private repo のため公開ダッシュボードから完全除外** (services.json も削除)。
- 過去スナップショットとの直接比較には注意 (divisor 38 → 43)。

今週は **Concordia が Lictor sidecar と双方向統合され spawn/permission/filesystem proxy + runtime kill switches 完備**、
**Pictor Phase 3 系統B 解体で外部 RenderPass/Attachment 注入 + PipelineCompiler 完成**、
**Ergo の render_pipeline plugin が visualizer から型付き編集 + sub-node 化まで一気拡大**、
**Bibliotheca が Corpus declarative UI へ完全移行 + 返却ランデブー**、
**新規 5 サービス (Corpus / Tirocinium / Aedilis / VantanHub / Schedula) が並列起動**、
**Lictor / Lector の新規 LUDIARS リポ追加** が並走した、 構造改革主体の 1 週間。
