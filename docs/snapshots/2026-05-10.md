## 横断的観察

### 依存の層構造

```
  [ゲーム層]    AdventureCube ── Tessera        Voluptas (Player profile)
                     │            │                │
  [エンジン層]  Ergo ──── Pictor ──── Synergos ──── Codex
                     │            │          │
                     │            │          └── Susurrus (chat)
  [テスト基盤]  Custos ── ergo_custos ── All-In-OneTest
                     │
  [エディタ層]  Ars ── Ars-Musa / Ars-PlatformPlugin / Ars-Module
                     │                │
                     ├── Iter (AST/呼出グラフエディタ)
                     │
  [サービス層]  Actio ── Discutere ── Imperativus ── Signum ── Curare ── Calicula
                     │                  │
                     │                  └── Hora (Desktop overlay)
                     │
  [代理人層]    Legatus (個人 PC 常駐) ── Memoria ── Quaestor (会計)
                     │
  [協調層]      Concordia (multi-agent coord)
                     │
  [基盤層]      Cernere ── Nuntius ── infra ── AIFormat ── LUDIARS (meta)

  [設計層]      Ludus (モジュールテンプレート) ── Educatus (?)
```

- **Memoria の TS 全面移行**: 5000 LOC の index.js / 3100 LOC の db.js
  / 1400 LOC の diary.js を含む全コードが TypeScript 化。 esbuild +
  eslint (no-explicit-any) で型安全性を担保した状態に移行、 アプリの
  保守性と LLM プロバイダ追加時の障壁が大きく下がった。
- **Susurrus 新設**: ローカルチャットの基盤として Synergos 上に乗る
  サービス。 Cernere 認証 + WebRTC/QUIC active 経路 + Synergos async
  休眠経路のハイブリッド設計、 さらに Overlay SDK で Pictor / Ergo /
  Unity 等から呼べる形を初日から計画。 v0.0 → v1.0 が 1 日で scaffold
  された (実装の磨き込みは継続中)。
- **Synergos の上位サービス hook**: PR #60 で peer stream extension
  hook を導入、 Susurrus / Tessera / 将来の AdventureCube ネット層が
  Synergos の transport を利用できる形に。 Synergos が「単独 P2P 基盤」
  から「LUDIARS 内ストリーム多重化基盤」 へ役割を拡張。
- **services.json のローカルログツール category 追加**: Memoria /
  Legatus / Concordia / Quaestor / Hora が公式登録され、 ダッシュボード
  カバレッジが 32 リポ (前週 28) に拡大。
