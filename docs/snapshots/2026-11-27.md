## 進んだこと

### タスク管理

Actio（10コミット）はタスクの一覧・詳細・書き込み、スプリント計画・履歴、チーム管理、イベントと予定などの HTTP 処理を Portus に移した。委託テンプレートをチームの AI メンバーとして登録して責任者に設定できるようにし、スクラムマスターにスプリントのフェーズ操作を許可した。

### セッション運用と公開ダッシュボード

Concordia（18コミット）は Discord のチーム相談で Bot が応答するようにし、画像だけの投稿の取り扱いとチームチャンネルの管理を改善した。Actio のプロジェクト登録を短時間再利用してタスク本文の取得を高速化し、オーバービューに AI サービス4社の週間残量表示を追加した。Lictor（2コミット）は Grok CLI のセッションログを中継し、ターンの切り替わり時に中継テキストの区分を確定するようにした。LUDIARS（1コミット）は11月26日の日報を反映した。

### 制作ツールと Unity 基盤

Praeforma（3コミット）はゲーム画面の取り込み、仕様に基づく表示提案と画像範囲の調整を追加した。保存時の変更通知と、Concordia の役割設定を使った実行時のモデル選択にも対応した。UnityFoundation（6コミット）はローカル main の更新で Foundation 2.0 の実装、フォルダ別の Unity パッケージ分割、依存関係の修正、バージョン管理が入った。6件には期間内にローカル main へ取り込まれた過去のコミットを含む。

### ログ収集とレビュー

Vestigium（4コミット）は VictoriaLogs への書き出しを C++ 実行ファイルに移し、Revisor ログの欠落から回復できるようにした。Revisor（2コミット）は同じコミットがマージ済みの場合の local PR 重複作成を防ぎ、Windows のサブモジュール取得時に名前解決の一時的な失敗を再試行するようにした。
