# LUDIARS サービス状況スナップショット (2026-07-05)

LUDIARS org の現役 **公開** リポジトリ (services.json 登録済) を、ローカル知識と
GitHub API (merged PR + commit since 2026-06-28) から解析した週次スナップショット。
前回 (2026-06-28) からの主な変化は冒頭サマリと「前回との比較」節にまとめます。

**注記 (2026-07-05)**:
- 前回から **7 日** の標準的な窓。比較は対 2026-06-28。
- **ダッシュボード集合は 40 リポで変動なし** (services.json への新規登録は今週ゼロ)。算術平均は **68%** で前回と同値 (2765→2739 の内訳変動はあるが四捨五入で同じ)。
- 今週は **登録済 40 リポの多く (24/40) が harness CI ゲート波及や favicon/vite 設定など事務的更新のみ** で、実質進捗は Ludellus-Server (+3) / Cernere (+2) / Lictor (+2) / Quaestor (+2) など一桁台の積み増しに留まった。±5pt 以上動いた登録リポは **ゼロ**。
- 一方 **未登録リポ側で大きな動きが継続**: **Pagus** (AI村シミュ、~60→~68、v1.4 一気通貫実装 13+ PR) / **Peregrinatio** (旅のしおり、~60→~65、GTFS時刻表統合) / **Lapilli** (共有tools monorepo、~40→~46、`@ludiars/blackbox` 成長型ブラックボックス共通パッケージ新設) / **Famulus** (~20→~25、blackboxでモデル切替を高度化) / **Thaleia** (~48→~52、統合ドメインビュー) が前進。**Lapilli の blackbox パッケージが Quaestor/Famulus/Pagus 複数リポで同時採用**され、org 横断の新しい共有基盤として定着し始めている。
- **新規リポ 2 件を発見** (未登録): **Augur** (テスト計画/修正方針サービス、spec+Phase0-2実装済) / **MemoriaPlugin** (Memoria プラグインフレームワーク host)。また **roadmap-\* 系 7 リポ** (非公開の事業ライン別計画ドキュメント、BACK-OFFICE/DX-WORKFLOW/PrivateGame/LUDELLUS/MUSA/PERSONAL-AI/SCHOOL-HUB) を新たに確認 — 実装リポではなく既存サービスを事業ライン別に整理した計画表 (services.json には載せない)。

今週は **Cernere が認証強度の底上げ (fail-fast secret/per-IP throttle/token短命化/refresh reuse検出等7点の一括hardening) で 90→92**、
**Lictor が地の文中継の stall 復帰watchdog + repin API で信頼性をさらに一段引き上げ (88→90)**、
**Ludellus-Server が学習POI完了通知+number_catch既定BehaviorSpec配布で仕様先行から実装追従 (46→49)**、
**Quaestor が未知payeeの科目学習に成長型ブラックボックスを採用 (72→74)** した以外は、
登録済リポの多くが harness CI ゲート波及と favicon/vite 設定の事務的更新に終始し、
**実質的な機能実装の主戦場は Pagus / Peregrinatio / Lapilli など未登録リポに移った** 7 日間だった。
