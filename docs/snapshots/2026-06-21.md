# LUDIARS サービス状況スナップショット (2026-06-21)

LUDIARS org の現役 **公開** リポジトリ (services.json 登録済) を、ローカルクローンと
GitHub API (merged PR + commit since 2026-06-14) から解析した週次スナップショット。
前回 (2026-06-14) からの主な変化は冒頭サマリと「前回との比較」節にまとめます。

**注記 (2026-06-21)**:
- 前回から **7 日** の標準的な窓。 比較は対 2026-06-14。
- 今週は **2 つの軸** に活動が割れた。 (1) **org 横断のコスメティック・配線スイープ** — 全 53 サービス分の favicon (raster + apple-touch + SVG) と **AIFormat 決定的チェックの CI ゲートをほぼ全リポへ配布** (Castra distribute-harness #18-#21)。 これらは pushed_at をほぼ全リポで今日付に揃えるが、 完成度はほとんど動かさない。 (2) **少数リポへの実質的な機能実装** — Quaestor 事業計画/補助金/投資アドバイザ、 Ludellus/Ludellus-Server のネイティブ MMO ワールド、 Tirocinium 企業 DB 大量 enrich + 求人クロール、 Discutere コスト計装、 AIFormat ハーネス転換。
- **新規 GitHub リポ (services.json 未登録) が大型化**: **Anatomia** (建築規約オラクル、 今週 35 PR で大幅成熟、 ~78%) と **Fundamentum** (共通データ基盤、 ~50%) が出現。 **UnityFoundation** は categories[] に登録済だが services{} 本体が欠落 (半登録)。 いずれも weighted_completion からは除外し .md で記述のみ。
- 進捗計算 (`weighted_completion`) は従来どおり **planned カテゴリ完全除外 + Foundation 除外** の公開 37 リポ算術平均。 前回と同一の 37 リポ集合 (Lector は登録保留継続のため引き続き avg 対象外) で apples-to-apples 比較。

今週は **Quaestor が事業計画レビュー + 補助金マッチング + 積立ポートフォリオ/配当/資産配分アドバイザを一気に実装して個人会計から「経営・資産形成」レーンへ拡張 (66→72)**、
**Ludellus / Ludellus-Server がネイティブ MMO ワールドクライアント (Ergo+Pictor) + サーバ権威ゲートウェイ + BehaviorSpec 駆動チューニングで「遊べる縦切り」へ前進 (40→50 / 35→44)**、
**Tirocinium が企業 DB を ~990 社 enrich + 求人ニュースクロール + 卒業生「裏口」面で就活データ基盤を厚くし (83→86)**、
**AIFormat が「書く前に揃えるハーネス」(HARNESS.md + CI ゲート + §7.1 無言フォールバック禁止) へ転換 (85→87)**、
**Anatomia (未登録) が warm supply/verify サーバ + Redis 共有キャッシュ + ドメインビュー + 構造レビュー生成で建築規約オラクルとして急成熟** した、 機能実装とハーネス標準化が並走した 7 日間。
