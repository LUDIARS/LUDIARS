# LUDIARS サービス状況スナップショット (2026-07-12)

LUDIARS org の現役 **公開** リポジトリ (services.json 登録済) を、ローカル知識と
GitHub API (merged PR + commit since 2026-06-28) から解析した週次スナップショット。
前回 (2026-07-05) からの主な変化は冒頭サマリと「前回との比較」節にまとめます。

**注記 (2026-07-12)**:
- 前回から **7 日** の標準的な窓。比較は対 2026-07-05。
- **ダッシュボード集合は登録済 40 リポで変動なし**。算術平均は **70%** (前回 68% → **+2pt**)。前週まで 2 週連続で「事務更新のみで実質進捗ゼロ」だった反動もあり、Figmentum (+7) / Schedula (+6) / Ludellus (+6) / Foedus (+5) / Ludellus-Server (+5) など登録済リポにも実質前進が戻った。
- **未登録リポ側でも大型の動きが継続**: Augur (テスト計画サービス、~25→~35、+10) / MemoriaPlugin (プラグインframework、~35→~45、+10) / Ostiarius (会場LANゲートウェイ、~25→~33、+8) が急伸。Anatomia (~84→~87) / Peregrinatio (~65→~69) / Lapilli (~46→~50) も引き続き前進。
- **新規リポ 2 件を発見** (いずれも private、2026-07-09 作成): **Calliope** (MUSA統括PM秘書オーケストレータ、創設3日でP0-P5をフル実装、~58%) / **Cocoiru** (在席共有+デスクトップ出席エージェント、Schedula系列、~35%)。
- **⚠ planned 枠の Voluptas で実質コミットを検知** (Ludellusプレイログ設計 + Discutere感情/タイムライン統合)。「未着手」前提の見直しを要検討 (下記「横断的観察」参照)。

今週は **Figmentum が敵自動生成 (gen-enemy MVP) + 棒人間幾何生成/splat→meshリトポで最も活発 (42→49)**、
**Schedula が Google Calendar 双方向同期を実装 (42→48)**、
**Ludellus が顔認識/位置認証ログイン設計 + Cernere WS顔識別クライアント + Suikaレンダラー移行で前進 (56→62)**、

**Ludellus-Server が学習POI通知配線に続き presence token spec を追加 (49→54)** した週で、
登録済リポの実質進捗が複数リポに分散して戻った 7 日間だった。
