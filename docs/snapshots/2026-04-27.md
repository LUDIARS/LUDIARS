## メタ / インフラ

### LUDIARS (meta)

- **概要**: LUDIARS 組織全体のメタリポジトリ。GitHub Pages
  ダッシュボード + All-in-One Docker Compose + 自動ホスト統合 CI を

  にマージ。

  連携とデプロイ自動化。
- **完成している機能**:

  - `scripts/integration-{up,down,wait,test,logs}.{sh,ps1}` (Windows 対応)

  - 週次 snapshots 自動更新 routine
- **未完成 / 次のタスク**:

## コアエンジン / SDK

### Ars

- 前週から変化なし (60%)。Tauri App 版ノードエディタとコア機能は完成。
  Axum Web 版・`ars-collab` は引き続き実装待ち。

### Ergo

  共通の入力・音響・パーティクル・UI 基盤。
- **完成度**: 78% (+3) — 今週 4 つの主要追加。
- **完成している機能 (今週追加)**:
  - **`ergo_custos`**: in-process HTTP/1.0 サーバ + 最小 PNG エンコーダ。
    ホスト ffmpeg gdigrab + nut-js を bypass し、アプリ自身が swapchain
    から直接 RGBA8 → PNG を返す。preview-status システムモジュール
    として登録 (`spec/module/custos.md`、9 tests)
  - **benchmarks/**: 外部依存なしの header-only ベンチマークハーネス。
    CPU パーティクル best-of-3 で ~20 ns/particle/frame ベースライン
  - **ergo_gpu_particle**: CPU fallback の shape sampling +
    burst cycles/interval 対応
  - **ergo_terrain**: Field カテゴリ拡張 (sand / water / lava / wood /
    ice parity)
  - **ergo_placer**: skill catalog 49 entries に拡張
- **未完成 / 次のタスク**:
  - GPU Compute Shader 統合 (Shuriken 相当)
  - プロファイリング・最適化
- **主要依存**: Pictor / FMOD Core fallback。main 一本運用継続。

### Pictor

- **概要**: データ駆動型 Vulkan / WebGL レンダリング基盤。
- **完成度**: 70% (+5) — 今週 4 つの主要コミット。
- **完成している機能 (今週追加)**:
  - **headless test suite** (PICTOR_BUILD_TESTS=ON 既定):
    frame_allocator / radix_sort / culling / pixel_text / fps_baseline。
    GPU フリーで CTest <4s
  - **hologram シェーダ**: SkillBox / Equipment 用 fresnel + scan-lines。
    既存 SceneUBO/InstanceData レイアウトと互換 (drop-in swap)
  - **WebGL frustum culling**: Gribb/Hartmann plane extraction +
    AABB p-vertex test、`WebGLFrameStats.culled_objects` 公開
  - **MaterialDesc ↔ JSON シリアライザ + tools/material-editor**
  - **mobile lifecycle API**: pause/resume/surface-lost + thermal
    auto-downgrade
  - **Android NDK 計画書** (`docs/android-build.md`): Phase 1-3
    (libpictor.a → headless emulator → 最小 APK Vulkan clear) と
    8 項目の未決事項を整理
- **未完成 / 次のタスク**:
  - Android (NDK) 実装着手 (AVX2 ARM fallback / AndroidSurfaceProvider)
  - ストリーミング LOD・遅延ロード
  - マテリアルエディタの Ars 連携
  - GaussianBlurEffect (GPU) ベース大領域 glow 高速化
