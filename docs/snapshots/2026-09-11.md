## 進んだこと

### セッション・復旧

**Concordia（11 commits）**: 復旧・受入ハーネスを追加。終了セッションの未回答質問を閉じ、閉鎖済み操作を拒否するようにした。設定とチーム構成の MCP 操作、workflow 別 Git 操作制御、チャットの入力・メディア・進行表示・関連作業の表示も整えた。

### 端末・運用

**Custos（1 commit）**: 所有する Android / iOS 端末の永続的な予約管理を追加した。

**Excubitor（4 commits）**: Android APK の supervisor 制御を追加。統合 Viewer を専用 DMZ ワーカーと独立した画面へ分離し、スマートフォンのメニュー表示と重なり順を修正した。残る表示確認はタスクとして記録されており、完了扱いにはしない。

### 仕様・画面編集

**Praeforma（6 commits）**: Web DOM/CSS の編集・import/export・隔離プレビュー、PC・スマートフォン別の画面定義、未整理断片の件数と再構築導線を追加した。Viewer の許可 Origin 設定と反映確認タスクも整備した。

**Anatomia / Quaestor（各1 commit）**: Excubitor Viewer への掲載を明示的に有効化した。Concordia と Praeforma にも対応する設定が入っている。

### 評価・開発基盤

**Revisor（2 commits）**: 複雑度をマージ阻害から独立した助言に変更し、プロジェクト全体の孤立関数を使う提案判定と stdin エラー耐性を追加した。

**Vitia（3 commits）**: 価値とパフォーマンスを独立評価する 2.0.0 を導入し、公開版とバージョン管理状態を同期した。

**AIFormat（1 commit）**: Concordia の受入フックと LLM を使わないオンタイムテストの共通設計を登録した。

**Ergo（1 commit）**: 依存ライブラリ込みの Visual Studio / Xcode プロジェクト生成を追加した。

**Schedula（1 commit）**: frontend・env-cli・SDK の依存を semver 非破壊範囲で更新した。
