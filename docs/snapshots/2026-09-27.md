## 公開予定のサービス

- **Orbis**：関心ごとにページをグラフで巡るデスクトップブラウザ。アセット / ツールに掲載。
- **Tela**：Pictor を使う再利用可能な C++ 宣言型ツール UI。UI / デザインシステムに掲載。

### Orbis の進捗

- **実装済み**：既存 Electron 版からの移行先として、Tela/Pictor の操作 UI と CEF/Chromium の Web 表示を組み合わせた Windows ネイティブホストを追加。戻る・進む・再読込と URL 表示を実装した。
- **残作業**：URL 入力、タブ、関心・履歴グラフ、既存データ、用途別設定、外部連携の移行。各 OS の配布とセキュリティ更新追従も完了条件に含む。既存版全体の移行完了ではない。
- **未確認**：IME・スクロール・DPI、終了時の子プロセス解放、待機 CPU/GPU などの実動作受入。本更新では実行していない。
- **根拠**：local `main` の `1873d3f7`。前回確認した commit から追加 commit はなく、仕様と移行・配布タスクに記録された実装状況・残件を継承した。

### Tela の進捗

- **実装済み**：宣言型 UI ランタイム、入力領域・ジェスチャー所有権、図形描画と対象追従ラベル、Pictor 描画アダプタ、Windows オーバーレイ、Unity Editor 連携と遷移編集サンプル、macOS AppKit オーバーレイアダプタを保持している。仕様書カード、シーン仮配置、ドメイン関係図の表示にも対応している。
